# Architecture Decision Record

The IMCS is a management-control platform for ADTrans RealIndo's property/real-estate business. Legal source documents identify KBLI 41011 (residential building construction), 68110 (owned/leased real estate), and 68200 (real-estate services on fee/contract basis). The application therefore models land, property, development, investment, finance, contracts, risk and governance.

The legacy Akvisio database is a source for migration, not the target architecture. No table or business value is invented when the source cannot be verified.
